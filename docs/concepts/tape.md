# Tape

Tape 的目的只有一个：忠实记录历史，让 agent 历史上的任意时刻都能被精确重建。

改进 harness，要在同一段历史上比较：回到 agent 当时所处的那一刻，换一种 harness 再走一遍。历史若只存成日志、散落的状态或被覆写的消息列表，那一刻就回不去，评估只能重跑真实对话，慢、贵，且结果不可比。Tape 让回到过去变成读一段前缀。

一盘录音带录下的是一段声音本身，想听哪一刻，倒回去就是。Tape 对 agent 做同样的事。

## 事实，而非状态

Tape 只记录发生过的事实，即 Event，不记录状态。给模型的上下文、界面的显示、各种统计，都从 Tape 读出，不单独存储。

账本记的是每一笔交易，余额是算出来的。余额可以从交易推出，交易无法从余额还原。状态是某一种 harness 对历史的解读，换一种 harness，解读随之改变，事实不变。只存事实，harness 才可以替换，同一盘 Tape 才能在不同的 harness 之间比较。

## 只追加

Tape 只在末尾追加，已录的 Frame 不修改、不删除、不重排。

真实的历史是线性的：时间只朝一个方向走，发生过的事不能撤回，也不能插队。磁带也一样，只朝一个方向录。只追加不是额外加上的约束，而是对历史本来面目的如实记录。

由此，任意一段前缀在任何时候读出的都相同，“第 i 帧之前”是一个永久有效的时刻。出了错不改写过去，纠正是一件新发生的事，追加在末尾，就像会计不涂改账本，只记一笔冲正。

## Frame

**Frame** 是 Tape 上的一条记录，只有两样东西：录入时间 `recorded_at`，和它承载的 Event。

Event 说发生了什么，Frame 说这件事何时被录下。如同信封上的邮戳，记的是邮局收到的时刻，不是写信的时刻。补写的事实没有可知的发生时刻，一次模型调用跨越一段区间而不是一个瞬间，唯一对所有事实都确定的，只有录入时间。

位置就是下标，从 0 开始连续，没有空洞，不存储在 Frame 里。磁带的位置由走带计数器读出，不写在磁带上。只追加已保证下标永久稳定，再存一份，就有了两个可以彼此偏离的来源。指向一帧，用 Tape 名加位置。

## Label

**Label** 是一盘 Tape 的身份：名字和创建时间。它与 Frame 分开存放，不参与回放，创建时写定，此后不改写。Label 在即 Tape 在。

磁带盒上的标签写着标题和日期，不放进机器就知道是哪一盘。Label 同理，只承载不读 Frame 就必须知道的事：列出所有 Tape 时不必逐盘读取，一盘空 Tape 也有身份。

会变的不进 Label。长度、轮数这类统计随每次录入变化，放进 Label 就成了 Frame 之外的第二个来源，崩溃时两者偏离，需要时由 Medium 自己索引。会被修改的信息，如标题，本身是发生过的事，录在 Tape 上。

已录的 Label 同样不可改写，新字段因此必带默认值，默认值描述的正是该字段出现之前的 Tape。
